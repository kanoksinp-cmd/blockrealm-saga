# Hobo — Emberfall Volcano

มอนสเตอร์สี่ขาแบบ voxel ลำตัวสีส้ม เกราะหินบะซอลต์สีเข้ม ปล่องบนหลังและหาง อ้างอิง [Hobo บน Pinterest](https://www.pinterest.com/pin/618048748864460823/)

- เลเวล 53 เกิด 4 ตัวใน Emberfall Volcano กลุ่มละ 2 ตัว
- ใช้ AI และระบบต่อสู้ของ Critter พร้อมกรามที่อ้าในช่วงง้างกัด และหางที่ส่ายได้
- ดรอป Obsidian Shard, Lava Core, Armor Stone หรือ Red Potion ตามโอกาส
- hobo_test.gd ตรวจจุดเกิดและการเดินบนพื้น การกัด การตาย และการเกิดใหม่จากแพ็กเกมจริง
