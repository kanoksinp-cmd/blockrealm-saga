# อัปเดตอาชีพและเควสถึงเลเวล 80

ต้นฉบับที่ใช้: Blockrealm_Saga_v1.0.0 (เกม 3 มิติ ไม่ใช่โปรเจกต์ Pixel Ayutthaya)
ต้นฉบับที่ปรับครบพร้อม assets อยู่ในโฟลเดอร์ career_expansion ของพื้นที่ทำงาน Blender
ไฟล์ในโฟลเดอร์นี้เป็น source patch ให้วางทับต้นฉบับ Godot เดิมตามโครงสร้างโฟลเดอร์

## อาชีพ
Novice เป็นขั้นเริ่มต้นแยกต่างหาก จากนั้นมีอาชีพ 5 ขั้น:
- นักดาบ → Knight → Lord Knight → Rune Knight → Dragon Knight
- นักธนู → Hunter → Sniper → Ranger → Windhawk
- นักเวท → Wizard → High Wizard → Warlock → Arch Mage
- Acolyte → Priest → High Priest → Arch Bishop → Cardinal
- Merchant → Blacksmith → Whitesmith → Mechanic → Meister
- Thief → Assassin → Assassin Cross → Guillotine Cross → Shadow Cross
แต่ละอาชีพยังมีสาย B แยกต่างหาก เช่น Royal Guard → Imperial Guard และ Sura → Inquisitor
ขั้น 4 ต้อง Base Lv45 / Job Lv40; ขั้น 5 ต้อง Base Lv65 / Job Lv30
มีสกิลขั้นสูงใหม่ 72 สกิล รวมแนวโจมตี ป้องกัน และสนับสนุน

## แต้มสกิล
ได้แต้มจาก Job Level และรางวัลเดิม โดยจำกัดงบแต้มไม่เกินผลรวมระดับสูงสุดของสกิลที่เรียนได้
ไม่มีแต้มส่วนเกินที่ใช้ไม่ได้เมื่อสกิลเต็ม เลือกอัปเองทีละแต้มได้ หรือกดลงแต้มสายโจมตี/ป้องกัน/สมดุลเพื่อใช้แต้มที่เหลือทั้งหมด
ปุ่มลงแต้มใช้เฉพาะแต้มที่ยังไม่ใช้ ไม่รีเซ็ตสกิลที่ผู้เล่นเคยเลือก
เซฟเดิมยังเก็บอาชีพและสกิลที่เรียนแล้ว

## เควส
เพิ่มเควสหลัก 27 ช่วง ต่อจากเนื้อเรื่องเดิมจนเลเวล 80 รวมภารกิจเปลี่ยนอาชีพขั้น 4 และ 5
เพิ่มคำร้อง NPC 18 เควส ให้ Guide Lumi, Merchant Toma, Blacksmith Doran, Captain Aldric, Old Sage Bren, Guild Clerk Mira
รับคำร้องด้วยการสนทนา สังหารเป้าหมาย กลับมารายงาน NPC จึงได้รับรางวัล
มีเครื่องหมาย ! / ? และติดตามในสมุดเควส; รับรางวัลซ้ำไม่ได้

## EXP
EXP ต่อเลเวล = (60 + Lv² × 25) × (1 + max(0, Lv−30) × 0.012)
มอนสเตอร์ต่ำกว่าเกิน 20 เลเวล: 10%; เกิน 10: 35%; เกิน 5: 65%
สูงกว่า 3–15 เลเวล: 115%; สูงกว่าเกิน 15: 50%; ช่วงอื่น: 100%
ตัวคูณนี้ใช้กับ EXP จากมอนสเตอร์และ EXP ที่แบ่งให้ปาร์ตี้ ไม่ลดรางวัลเควส
Base Level สูงสุดยัง 99; เรื่องหลักจบเลเวล 80

## ตรวจสอบ
Godot 4.7.2: 1,467 assertions ผ่าน ครอบคลุม 6 อาชีพ × 2 สาย × 5 ขั้น, งบแต้ม, ลงแต้มครบ,
เงื่อนไขเปลี่ยนอาชีพ, EXP, เป้าหมายมอนสเตอร์, รับรางวัลซ้ำ, เซฟ และการสร้าง UI ทั้ง 6 แท็บ
ใช้ user data แยกใน career_runtime ระหว่างทดสอบ ไม่แตะเซฟผู้เล่นจริง
