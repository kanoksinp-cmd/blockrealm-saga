# Verdant Ruins — Ashfang Rex and Mossjaw Rex

- Ashfang Rex เลเวล 70 เกิดหนึ่งตัวทางตะวันตกเฉียงเหนือที่ (923.5, -39.5) เกิดใหม่ 150 วินาที
- Mossjaw Rex เลเวล 60 เกิดหนึ่งตัวทางตะวันออกเฉียงใต้ที่ (1071.5, 66.5) เกิดใหม่ 120 วินาที
- บอสทั้งสองพุ่งกัด มีกรามและหางขยับ ตำแหน่งห่างกันเกินระยะไล่ของทั้งคู่
- ทั้งสองดรอปหินตีบวกและวัตถุดิบตามสูตรของแต่ละตัว

โมเดลสร้างด้วย BoxModel ตามภาพ [Ashfang](https://www.pinterest.com/pin/678847343872712200/) และ [Mossjaw](https://www.pinterest.com/pin/1047720300800744052/) ทดสอบจำนวน การกลับเข้าแผนที่ จุดเกิด โมเดล กราม การตายและเกิดใหม่ผ่านแพ็กเกม
