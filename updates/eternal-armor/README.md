# Eternal Armor

ชุดแฟชั่นเกราะทองและคริสตัลฟ้าแบบ voxel ที่สร้างด้วยโมเดลของเกม อ้างอิงรูป [Minecraft Eternal Armor](https://www.pinterest.com/pin/698339486021000108/) (Hydra Team / AlanizMc9)

- คราฟที่ Blacksmith Doran ในแท็บแฟชั่น ใช้ Gold Ore 8, Mithril Ore 4, Sapphire 2 และ 15,000 Zeny
- ปลดล็อกต่อตัวละคร ใส่ได้ทุกอาชีพ สวมและถอดจากเมนูแฟชั่นในกระเป๋า
- ปีกคริสตัลเป็นส่วนหนึ่งของโมเดลชุด ชุดไม่มีโบนัสค่าสถานะ
- รูปเต็มตัวในร้านและเมนูมาจากการเรนเดอร์โมเดลเกม

แพตช์นี้ต่อจาก ed92038 และใช้รูปแบบ save และ craft เดียวกับชุดก่อนหน้า
`source/` เก็บไฟล์ Godot ที่เปลี่ยนและรูปเต็มตัวต้นฉบับ
`eternal_test.gd` ทดสอบสูตรทั้ง 7 กลุ่มอาชีพ การสวมถอด เซฟ/โหลด โมเดล รูปชุด และเมนูร้าน
