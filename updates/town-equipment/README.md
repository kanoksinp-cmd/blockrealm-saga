# หมวดคราฟ หมวก ผ้าคลุม แผงยา และดาบพื้นฐาน

## การใช้งาน
ไปหา Blacksmith Doran แล้วเลือกหมวด ตีบวก / อาวุธ / หมวก / เกราะ / เครื่องประดับ / ปีก / แฟชั่น / วัสดุ
หมวดอาวุธแยกย่อยตามชนิด ดาบ ขวาน ธนู คทา มีด หอก ดาบใหญ่ กระบอง ตำรา กาตาร์ สนับมือ แส้ และเครื่องดนตรี
สูตรซ้ำจากคอลเลกชันเก่าถูกรวมให้เหลือสูตรเดียวต่อไอเท็ม วัตถุดิบและต้นทุนของสูตรเดิมคงไว้
การคราฟสำเร็จจะบันทึกทันที

หมวกใหม่ 21 แบบอยู่ในหมวดหมวก คราฟแล้วสวมที่ช่อง Head ได้ทุกอาชีพ ชื่อหมวกแสดงเป็นภาษาไทย
ผ้าคลุมมาตรฐาน ผ้าคลุมจากอุปกรณ์ และผ้าคลุม Forest Mage พลิ้วด้วยลมแม้ยืนเฉย
ขอบบนติดกับตัวละคร ชายผ้ามีตาข่ายย่อยและน้ำหนักลม ไม่แกว่งทะลุเข้าตัว
รัศมีตีบวกขยับตามผ้า และนาฬิกาลมยังทำงานขณะพักเกม

Merchant Toma มีแผงขายยาผ้าใบฟ้า ขวดยา ชั้นวาง และป้ายร้าน
แผงเป็นส่วนหนึ่งของ NPC จึงคลิกเปิดบทสนทนาร้านได้ มีจุดยืนสนทนาหน้าเคาน์เตอร์และการชน
ร้านยังขายสินค้าตามเดิม ขวดยาแดง/น้ำเงินใช้โมเดลใหม่ในไอคอน ภาพหมุน และของตกพื้น
ผลฟื้นฟูเดิม: HP70 / SP40 ขวดเขียวและสีอำพันเป็นของตกแต่งในร้าน
ดาบเริ่มต้นและ Iron Sword ใช้ดาบเหล็กทรงอ้างอิงใหม่ ค่าสถานะ ราคา และรหัสไอเท็มเดิมคงไว้
