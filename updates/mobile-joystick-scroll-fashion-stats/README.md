# Mobile joystick-only movement, context action button, smooth list scrolling, fashion stats (2026-11-05)

- Phones: bare-ground taps no longer walk (no hold-to-walk either); move with the joystick only.
  Tapping a monster / NPC / loot / gather spot still targets it.
- Action button changes with what is near: quest bubble "เควส" (NPC with ! / ?), "คุย" (NPC),
  "เก็บ" (loot within 3 m or gather spot), otherwise the sword. Pressing it walks over and talks /
  picks up via talk_to.
- Windows: finger drags inside any scrollable list scroll it 1:1 even when the finger starts on a
  button; the press is cancelled, and the list keeps gliding with momentum after release.
- Every fashion set now gives stats (Relic Vanguard sets, Eternal Armor, Forest Mage), shown in the
  fashion card like the Hallow Spectres sets.
