# Relic Vanguard

แฟชั่นทั้ง 12 เซ็ตเรียงตาม [ภาพอ้างอิง](https://www.pinterest.com/pin/683210206013988100/) พร้อมอาวุธตามเซ็ต และโล่สำหรับ Crimson Bastion, Iron Warden และ Azure Bulwark

- คราฟที่ Blacksmith Doran ในแท็บแฟชั่น ใช้ 12,000 Zeny กับวัตถุดิบสองชนิดตามสูตรของแต่ละเซ็ต
- ปลดล็อกเป็นชุดต่อตัวละคร ทุกอาชีพสวมได้จากกระเป๋า → แฟชั่น
- โมเดลอาวุธผูกกับจุดจับของอาวุธที่สวมอยู่ อาวุธและโล่แฟชั่นเปลี่ยนรูปลักษณ์ ส่วนพลังและแอนิเมชันต่อสู้อิงอุปกรณ์จริง
- แฟชั่นใหม่อยู่หน้าแรกของเมนูและโปรโมทอยู่ก่อนกรอบเล่นเกม ส่วนภาพการ์ดและโปสเตอร์เรนเดอร์จากโมเดลเกม
- relic_test.gd ทดสอบคราฟ การสวม โมเดลอาวุธและโล่ รูปเต็มตัว เซฟและโหลด และการเปิดจากเมนูแฟชั่นและร้านคราฟ
