Mobile landscape, readable UI text and refine-level transfer

Mobile uses a landscape logical canvas with an adaptive short side capped at 480 logical pixels. EXPAND preserves scene proportions on landscape aspect ratios; KEEP letterboxes portrait while the browser displays a rotate-phone overlay. Account fullscreen orientation requests and the new manifest prefer landscape. Unsupported browser orientation locking is caught and the manual rotate prompt remains. PC orientation/layout and mobile rendering/FPS resource caps are retained.

Touch controls use 60-logical-pixel square action targets, separated dock columns/rows, independent finger indices, and gesture cancellation on resize. A joystick held during resize cancels its movement. The landscape map uses a horizontal map/list layout, correct 512-coordinate scaling and bounded popup size. Clock anchoring reserves its final text width. Equipment dropdown icon width is capped to avoid 128-pixel icons forcing enormous rows. Smith tabs wrap without forcing horizontal overflow.

UI labels use minimum 15 logical pixels on mobile and 13 on PC, with lighter secondary text and button captions at 15/14. Existing Prompt-family font resources retain their 2x oversampling, hinting and linear sampling. Pixel art/icons and Ragnarok damage digits keep their existing rendering. No extra font atlas or 3D rendering load is introduced.

Refine transfer: Blacksmith -> โอนตีบวก. Owned equipped/bag gear must use the same equipment slot and, for weapons, the same weapon type. Source level must exceed target; source becomes +0, target receives the source level, and target's prior level is replaced rather than added. Fee is 1,000 * source_level squared Zeny (e.g. +5 costs 25,000; +10 costs 100,000). No gear or stones are consumed. The original game stores refine by item ID, shared by all copies of a name; this existing behavior is stated on the confirmation screen. Same-name transfers are rejected. Confirmation is revalidated for ownership, levels, funds and nearby living-player/smith context. Save failure rolls back levels and money. Saving now returns a success boolean; existing callers may ignore it. Success is emitted only after persistence, and selections are cleared to prevent repeated spending.
