# Ragnarok-style combat numbers

Combat damage now uses pixel digits projected over the hit position with a hop and fade. Normal hits are white, incoming hits red, poison green, and critical hits gold over a rust-colored burst. Rapid hits fan out and MISS is included in the damage-number setting.

FX still receives the existing damage and color signals. Combat math and the generic world-label path for EXP, loot, healing and skills are untouched. Uses the existing BlockrealmPixel font (OFL).
