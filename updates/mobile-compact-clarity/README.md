Compact mobile HUD and bounded high-resolution rendering

Only mobile presentation changes. The landscape status panel now uses the smaller existing compact header. The toolbar consolidates the six persistent navigation buttons into the existing menu plus bag/skills/party shortcuts; the party shortcut moves into the menu on narrower scaled viewports. Party roster details remain available in the party window. The smaller quest card and clock hide when there is insufficient space above touch actions; quest/party functions remain accessible from the menu. Four skills form a right-thumb arc around the attack button; quick items, AUTO and page switch use a short bottom row, leaving the center of the scene unobstructed. The large rectangular dock is hidden while 60-logical-pixel touch targets are retained.

The mobile renderer requests up to 1.25 device pixel ratio instead of 1.0, bounded by 1280 long-side pixels, 720 short-side pixels and approximately 720,000 total pixels. Typical 844x390 retina phones draw at 1055x488. Old mobile-performance.js remains untouched for cached old clients; new HTML loads a content-versioned mobile-clarity script. FPS stays 30, hidden FPS stays 5, and no shadows, extra particles, antialiasing or font atlases are added. More pixels can increase GPU work; no claim of physical-device thermal performance is made.

Bug fix: layout dimensions now use CSS viewport size instead of framebuffer pixel dimensions in Web builds, so higher rendering resolution does not shrink touch targets. Native tests emulate the separate render pixel ratio. Mobile UI scaling is limited to 95-110 percent and its slider reflects that range; desktop retains 75-150 percent. Collision checks cover header/navigation/minimap, every action pair, quest/clock versus actions, and the main popup bounds across several phone/tablet aspect ratios at all three mobile UI scales.

Tests passed for 844x390, 667x320, 932x430 and 1024x768 CSS viewports at 1.25 render ratio and 95/100/110 percent UI size. Existing gesture regression covers simultaneous joystick/button fingers, rotation cancellation, modal blocking, target sizes and map scaling. The JavaScript profile test verifies bounds, pixel aspect preservation, orientation/resize restoration, sharper phone output and untouched desktop resize policy. Native OpenGL HUD/map/transfer screenshots were reviewed for mobile and PC. No physical iPhone/Safari test was available. Existing Godot full-scene shutdown resource warnings remain after test PASS markers.

Exact pack diff allows settings.gd, mobile_hud_pc.gd, ro_ui_mobile.gd and the UI-scale slider bounds in ro_ui_base.gd only. All combat, refine transfers, maps, account/cloud formats, saved character appearance, last-position resume and PC HUD are otherwise preserved.
