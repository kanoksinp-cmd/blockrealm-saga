# Forge Arsenal

Twelve equippable weapons based on selected silhouettes from [Andy Cotnam’s Hero Academy 2 reference](https://www.pinterest.com/pin/354025220711311143/). Each has a distinct voxel model and an inventory icon drawn from the same original pixel grid.

Craft at Doran → Weapons. Recipes and equipping both check Base Level 60–80, and equipping also follows the existing class weapon rules. ATK and bonuses use the normal equipment and refinement paths. Arsenal recipes are first in their applicable filters.

arsenal_test.gd exercises all twelve levels, recipes, material and Zeny consumption, class gates, grip models, icons and equipment save/reload. render_arsenal.gd renders the displayed models from Godot.
