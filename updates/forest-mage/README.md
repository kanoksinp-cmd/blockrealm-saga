# Forest Mage — แฟชั่นนักเวท

ใช้โมเดล forest_mage_flying_pets.blend ที่ผู้ใช้ให้มา ส่งออกด้วย Blender 5.2.2 LTS
ไฟล์ต้นฉบับ Blender ของผู้ใช้ไม่ถูกแก้ไข

## ใช้งาน
1. เป็นอาชีพ Mage หรืออาชีพขั้นสูงสายเดียวกัน แล้วไปหา Blacksmith Doran
2. เปิดโรงตีอุปกรณ์ แท็บ “แฟชั่น” และคราฟ Forest Mage
3. ใช้ Living Vine 12, Moss Clump 15, Blossom Petal 8, Treant Heart 1 และ 10,000 Zeny
4. คราฟครั้งเดียวปลดล็อกถาวรเฉพาะตัวละครนั้น คราฟซ้ำไม่ได้
5. เปิดกระเป๋า I → แฟชั่นนักเวท → สวม Forest Mage หรือถอดแฟชั่น

แฟชั่นประกอบด้วยหมวก เสื้อคลุม รองเท้าบูต คทาตกแต่ง และภูตบินสองตัว
ชุดและคทาเป็นภาพตกแต่ง ไม่เพิ่ม ATK, DEF, HP, SP หรือเปลี่ยนอุปกรณ์จริง
ภูตบินเป็นส่วนตกแต่ง ไม่โจมตีหรือให้โบนัส เซฟการสวมอยู่ใน appearance.fashion และสิทธิ์คราฟอยู่ใน fashion_unlocks
ตัวละครใหม่และเซฟเก่าที่ยังไม่เคยคราฟต้องคราฟก่อน ระบบไม่แจกชุดให้ฟรี
ส่งต่อรูปลักษณ์ผ่านระบบออนไลน์เดิม และคืนรูปลักษณ์อุปกรณ์เดิมเมื่อถอด

## การประกอบโมเดล
6 ชิ้นแยกต่อกับจุดหมุน head, torso, arm_l, arm_r, leg_l, leg_r ของ rig เดิม
คทามีจุดจับแยกเพื่อเล่นท่าร่ายเวท ภูตเก็บ animation hover/wing จากต้นฉบับและวนซ้ำในเกม
ไฟล์ glb ใน assets/models/forest_mage ใช้กับ source patch ใน scripts
ให้ใช้ patch นี้หลัง updates/career-level80 หากกำลังประกอบต้นฉบับจากแพตช์

## ตรวจสอบ
Forest fashion: 40 assertions ผ่าน (สวม/ถอด, อาชีพ, ค่าสถานะ, เซฟ, network sanitizer,
ชิ้นส่วนโมเดล, ภูตบิน, ท่าเดิน/ร่ายเวท, การเปิดเมนู, ห้ามสวมก่อนคราฟ,
หักวัตถุดิบและเงินตรงสูตร, ป้องกันคราฟซ้ำ, ป้องกันสูตรดัดแปลง และไม่ส่งสิทธิ์ข้ามตัวละคร)
Career regression: 1,467 assertions ผ่าน
ทดสอบผ่าน user data แยกจากเซฟผู้เล่นจริง
ยังไม่ได้ทดสอบออนไลน์หลายเครื่องพร้อมกัน
